# 秋招速投

面向个人求职者的投递工作台：导入基础简历，粘贴岗位 JD，逐条确认定向修改，生成岗位版简历和官网填写材料，并跟踪投递状态。

## 在线演示

[打开只读产品演示](https://autumn-job-fast-apply.ddjsgzx.chatgpt.site/demo)

演示页面使用虚拟数据，所有操作仅在浏览器内模拟，不保存内容、不调用 AI，也不会访问正式工作台中的个人数据。

## 核心能力

- 基于原版简历为不同岗位生成独立版本
- 拆解 JD 并给出可接受、拒绝和编辑的修改建议
- 在简历预览中标注新增、删除和修改内容
- 导出一页式 PDF、DOCX 和 Overleaf 源码
- 生成官网字段、自我介绍和开放题答案
- 使用投递看板跟踪待投递、笔试、面试和 Offer

## 隐私边界

正式工作台要求登录，结构化数据按用户隔离。OpenAI API 密钥只配置在服务端环境中，不应写入源码或提交到 GitHub。

## 本地运行

```bash
npm install
npm run dev
```

复制 `.env.example` 中的变量到本地环境文件，并在部署平台配置对应服务端密钥与 D1/R2 绑定。
